# 흑색잔상 데브로그 사이트

- 한국어: https://unit926.github.io
- 영어: https://unit926.github.io/en/

글은 **한글판과 영문판을 짝으로** 쓴다.

첫 화면(`/`)은 **926호 현관과 방**이다(2026-10-17). 데브로그 목록은 `/devlog/` 에 있고, 방 책상 위 컴퓨터를 누르면 그리로 간다. 일기는 방 넷째 벽 수납장 서랍에서 연다.
방 그림과 움직임은 `src/components/Room.astro` 한 파일에 있다. 이을 곳 주소(Steam · 디스코드 · 메일 · 아트스테이션 · 재생목록)는 **그 파일 맨 위 `LINKS` 만 채우면** 된다. 빈 칸이면 그 창에 「준비 중입니다.」가 뜬다.

---

## 글 한 편 올리는 순서

바탕화면 폴더 **「흑색잔상 데브로그」** 안의 번호를 순서대로 누르면 된다.

### 1. 새 글 만들기

`1. 새 글 만들기` 를 누른다.

글 파일이 **두 개** 생긴다.

- 한글판 → `src/content/devlog/`
- 영문판 → `src/content/devlog-en/`

둘은 맨 위 `slug` 값이 같아서 짝으로 묶인다. 이 값이 인터넷 주소가 된다.
**파일 이름은 옵시디언에서 마음대로 바꿔도 된다. 주소와 상관이 없다.**
`slug` 줄만 건드리지 않으면 된다.

### 2. 사진을 넣는다

`2. 사진 넣는 곳 열기` 를 눌러 폴더가 열리면, 사진 원본을 전부 거기 넣는다. 크기는 신경 안 써도 된다.

그다음 `3. 사진 줄이기` 를 누른다.
사진이 가로 1600픽셀로 줄어서 `src/assets/devlog/` 에 들어가고, 원본은 `처리완료` 폴더로 옮겨진다.
**원본은 저장소에 안 올라간다.**

화면에 나온 줄을 복사해서 글에 붙여 넣는다.

```
thumbnail: ../../assets/devlog/2026-09-17-01.webp
![](../../assets/devlog/2026-09-17-02.webp)
```

사진은 한글판과 영문판이 같은 것을 쓰면 된다. 붙여 넣는 줄도 똑같다.

### 3. 글을 쓴다

옵시디언으로 두 파일을 열어서 쓴다. 맨 위 `---` 와 `---` 사이가 글의 정보다.

| 항목 | 무엇 |
|---|---|
| `title` | 목록과 글 맨 위에 뜨는 제목 |
| `date` | 글 날짜. 목록은 이 날짜 순으로 정렬된다 |
| `summary` | 목록에 제목 아래 한 줄로 뜨는 소개. 지워도 된다 |
| `thumbnail` | 목록에 뜨는 그림 |
| `thumbnailAlt` | 그림이 안 뜰 때 대신 읽히는 설명 |
| `draft` | `true` 면 내 컴퓨터에서만 보인다. `false` 로 바꿔야 공개된다 |
| `slug` | 인터넷 주소. **건드리지 않는다** |

### 4. 내 화면에서 확인한다

`4. 미리보기 켜기` 를 누르면 잠시 뒤 브라우저가 열린다.
글을 고치면 저장하는 즉시 화면이 바뀐다. 멈추려면 그 검은 창에서 `q` 를 누르고 엔터.

**여기서 보이는 것은 내 컴퓨터 안에서만 보인다. 밖으로 안 나간다.**

### 5. 올린다

두 파일의 `draft` 를 `false` 로 바꾼 다음 `5. 올리기` 를 누른다.

누르면 이렇게 돈다.

1. 사이트가 제대로 만들어지는지 먼저 확인한다 — **깨졌으면 올리지 않고 멈춘다**
2. 바뀐 것을 담고 오늘 날짜로 기록을 남긴다
3. 깃허브로 올린다

2~3분 뒤 사이트에 반영된다.

## 일기 한 편 올리는 순서

일기는 **한글판 한 편만** 쓴다. 방 넷째 벽 수납장 서랍을 누르면 뜨는 일기장에 날짜 순으로 쌓인다.

1. 바탕화면 폴더의 `6. 새 일기 만들기` 를 누른다. `src/content/diary/` 에 일기 파일이 하나 생긴다.
2. 옵시디언으로 열어서 쓴다. 맨 위 `title` 이 일기장에 뜨는 제목이다.
3. `4. 미리보기 켜기` 로 내 화면에서 확인한다. 방에서 서랍을 눌러 보면 된다.
4. 맨 위 `draft` 를 `false` 로 바꾸고 `5. 올리기` 를 누른다.

**올리는 순간 누구나 읽는다.** 일기에는 사진을 안 붙인다.

## 폴더가 무엇을 하나

| 폴더 | 무엇이 들어 있나 |
|---|---|
| `src/content/devlog/` | **한글판 글** |
| `src/content/devlog-en/` | **영문판 글** |
| `src/content/diary/` | **일기.** 한글판만 |
| `src/components/Room.astro` | **첫 화면 현관과 방.** 그림 · 움직임 · 이을 곳 주소(맨 위 `LINKS`) |
| `src/assets/devlog/` | **사진.** 줄여진 것만 들어온다 |
| `_사진넣는곳/` | 사진 원본을 던져 넣는 자리. 저장소에 안 올라간다 |
| `_쓰는중/` | 다 쓰기 전의 글을 두는 자리. 저장소에 안 올라간다. 다 쓰면 `src/content/devlog/` 로 옮기고 맨 위 정보 칸을 붙인다 — 정보 칸 없는 글이 글 폴더에 있으면 사이트가 안 만들어진다 |
| `src/styles/global.css` | **겉모습.** 색·글꼴·칸 배치가 전부 여기 있다 |
| `src/lib/i18n.ts` | 화면에 뜨는 말(탭 이름 등). 두 언어가 여기 모여 있다 |
| `src/layouts/` · `src/components/` | 화면의 틀. 레이아웃을 바꿀 때 건드리는 자리 |
| `src/pages/` | 한국어 탭 세 개 |
| `src/pages/en/` | 영어 탭 세 개 |
| `바로가기/` | 바탕화면 단추가 실제로 부르는 파일들 |
| `.github/workflows/` | 푸시하면 깃허브가 사이트를 자동으로 만드는 설정 |
| `dist/` | 만들어진 결과물. 손대지 않는다. 저장소에 안 올라간다 |

---

## 겉모습을 바꾸고 싶을 때

색과 글꼴은 `src/styles/global.css` 맨 위 `:root` 안에 모여 있다.
거기 값만 바꾸면 사이트 전체가 같이 바뀐다. **글 파일은 하나도 안 건드린다.**

---

## 되돌리는 법

- 글 한 편을 안 보이게 하려면 그 글 맨 위 `draft` 를 `true` 로 바꾼다.
- 글을 아예 없애려면 그 파일을 지운다. 한글판과 영문판 둘 다 지운다.
- 사이트 전체를 없애려면 이 폴더와 깃허브 저장소를 지운다. 다른 데에 영향이 없다.

## 명령으로 직접 할 때

| 명령 | 무엇을 하나 |
|---|---|
| `npm run new` | 새 글 두 개(한글·영문)를 만든다 |
| `npm run diary` | 새 일기 한 편을 만든다 |
| `npm run images` | `_사진넣는곳` 의 사진을 줄여서 넣는다 |
| `npm run dev` | 내 컴퓨터에서 사이트를 띄운다 |
| `npm run deploy` | 확인하고 올린다 |
| `npm run build` | 만들어지는지만 확인한다 |

날짜를 직접 정하려면 뒤에 붙인다. 예: `npm run new -- 2026-09-30`
