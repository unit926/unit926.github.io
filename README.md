# 흑색잔상 데브로그 사이트

주소: https://r4mh0.github.io

---

## 글 한 편 올리는 순서

### 1. 사진을 먼저 넣는다

사진 원본을 `_사진넣는곳` 폴더에 전부 넣는다. 크기는 신경 안 써도 된다.

그리고 이 명령을 돌린다.

```
npm run images
```

사진이 전부 가로 1600픽셀로 줄어서 `src/assets/devlog/` 에 들어가고,
원본은 `_사진넣는곳/처리완료/` 로 옮겨진다. **원본은 저장소에 안 올라간다.**

화면에 이런 줄이 나온다. 다음 단계에서 복사해 쓴다.

```
thumbnail: ../../assets/devlog/2026-09-17-01.webp
![](../../assets/devlog/2026-09-17-02.webp)
```

날짜를 직접 정하고 싶으면 `npm run images -- 2026-09-17` 처럼 뒤에 붙인다.

### 2. 글 파일을 만든다

```
npm run new
```

`src/content/devlog/` 안에 오늘 날짜로 된 글 파일이 하나 생긴다.
옵시디언으로 그 파일을 열어서 쓴다.

맨 위 `---` 와 `---` 사이가 글의 정보다.

| 항목 | 무엇 |
|---|---|
| `title` | 목록과 글 맨 위에 뜨는 제목 |
| `date` | 글 날짜. 목록은 이 날짜 순으로 정렬된다 |
| `summary` | 목록에 제목 아래 한 줄로 뜨는 소개. 지워도 된다 |
| `thumbnail` | 목록에 뜨는 그림. 1단계에서 나온 줄을 붙여 넣는다 |
| `thumbnailAlt` | 그림이 안 뜰 때 대신 읽히는 설명 |
| `draft` | `true` 면 내 컴퓨터에서만 보인다. `false` 로 바꿔야 공개된다 |

### 3. 내 화면에서 확인한다

```
npm run dev
```

브라우저에서 `http://localhost:4321` 을 연다.
글을 고치면 저장하는 즉시 화면이 바뀐다. 멈추려면 `q` 를 누르고 엔터.

### 4. 올린다

맨 위 `draft` 를 `false` 로 바꾼다.
그다음 커밋하고 푸시한다. 2~3분 뒤에 사이트에 자동으로 뜬다.

## 폴더가 무엇을 하나

| 폴더 | 무엇이 들어 있나 |
|---|---|
| `src/content/devlog/` | **글 파일.** 여기만 늘어난다 |
| `src/assets/devlog/` | **사진.** 줄여진 것만 들어온다 |
| `_사진넣는곳/` | 사진 원본을 던져 넣는 자리. 저장소에 안 올라간다 |
| `src/styles/global.css` | **겉모습.** 색·글꼴·칸 배치가 전부 여기 있다 |
| `src/layouts/` · `src/components/` | 화면의 틀. 레이아웃을 바꿀 때 건드리는 자리 |
| `src/pages/` | 각 탭. `about.astro` 가 소개, `presskit.astro` 가 프레스킷 |
| `.github/workflows/deploy.yml` | 푸시하면 깃허브가 사이트를 자동으로 만드는 설정 |
| `dist/` | 만들어진 결과물. 손대지 않는다. 저장소에 안 올라간다 |

---

## 겉모습을 바꾸고 싶을 때

색과 글꼴은 `src/styles/global.css` 맨 위 `:root` 안에 모여 있다.
거기 값만 바꾸면 사이트 전체가 같이 바뀐다. **글 파일은 하나도 안 건드린다.**

---

## 되돌리는 법

- 글 한 편을 안 보이게 하려면 그 글 맨 위 `draft` 를 `true` 로 바꾼다.
- 글을 아예 없애려면 `src/content/devlog/` 에서 그 파일을 지운다.
- 사이트 전체를 없애려면 이 폴더와 깃허브 저장소를 지운다. 다른 데에 영향이 없다.

## 도구 목록

| 명령 | 무엇을 하나 |
|---|---|
| `npm run dev` | 내 컴퓨터에서 사이트를 띄운다 |
| `npm run new` | 새 글 파일을 만든다 |
| `npm run images` | `_사진넣는곳` 의 사진을 줄여서 넣는다 |
| `npm run build` | 올리기 전에 제대로 만들어지는지 확인한다 |
